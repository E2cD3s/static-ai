What it's learned

How it has adapted to each server: reply length, how long it waits for a follow-up, and which way of answering each mood has gone down better. Admin only.

Platforms

Static runs as two bots in one process: one on Discord, one on your Fluxer server. They share the models (LLM, speech, voice) and the persona, and each keeps its own people, memories, mood learning, tuning and reminders. Turn either one off here - at least one stays on, since the models and this dashboard live in the same process. Changes apply when the bot restarts (about 30 seconds, voice calls drop).

Live

What Static hears in voice and says back, and the text chat it answers, as it happens. Only the last 400 lines are kept, in memory, and they're gone after a restart; DMs aren't shown. Mute stops every reply in that server, voice and text, but it keeps listening and following the conversation. It stays muted across restarts until you unmute it.

Servers

People

Everything Static keeps about each person: who they are, the notes the LLM writes about them (data/profiles.db), the raw lines waiting to be summarized into those notes, and their tone-of-voice baseline and mood thresholds (data/mood.json). People can see their own with /profile, and delete it with /forget or /profiling. Discord and Fluxer keep separate records - switch above.

off Profiles are turned off in Settings (profiles › enabled), so nothing new is being collected.

Pick someone to see what's stored.

Settings

Saved to config.yaml (comments kept, previous version backed up to data/config.backup.yaml). Most settings apply immediately; restart ones need a restart, next join ones apply the next time it joins voice. Secret fields are never shown: leave them blank to keep the current value.

Remove Static from ?

It leaves the server right away. Getting it back needs a server admin to use the invite link again. Type the server's name to confirm.

Add Static to a server

Bots can't join servers by themselves. Open this link (or send it to a server admin); Discord asks which server to add it to. Slash commands show up once it's in: use Enable commands on its card if your config limits them to specific servers.

Forget ?

Deletes their profile notes, queued lines, avatar description, tone baseline and mood thresholds. It starts collecting again the next time they talk, unless you turn profiling off for them. Reminders they set aren't touched.

Restart the bot?

It drops out of voice for about 30 seconds while the models reload, then rejoins nothing by itself (unless voice.auto_join_channel_id is set). This page reconnects when it's back.
